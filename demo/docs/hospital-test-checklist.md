# 医院场景验收测试清单

## 1. 健康管理师/医生助手

- 登录后可以进入患者管理、报告管理、随访任务、随访知识库与模板。
- 患者列表能看到所属科室、主要负责医生、健康管理师。
- 能打开患者详情，查看档案、报告、随访任务和报告随访建议。
- 能基于已审核报告创建报告后随访任务。
- 发送随访任务后，能拿到公开打卡入口。
- 小程序或公开链接提交后，B端随访任务里能看到打卡记录。

## 2. 医生

- 登录后默认进入医生工作台。
- 只能看到自己作为主要负责医生的患者。
- 能看到自己的患者报告待填写建议列表。
- 能填写并提交“报告随访建议”。
- 不能看到健康管理师的运营操作入口。
- 不应创建、修改、关闭随访任务。

## 3. 科室主任

- 登录后默认进入科室看板。
- 只能查看本科室患者、医生统计和异常患者。
- 不填写督办意见。
- 不进入健康管理师操作流程。
- 跨科室患者不应出现在科室看板中。

## 4. 患者端小程序/公开链接

- 使用任务码可以获取本次随访任务。
- 能提交文字反馈。
- 能上传 PDF/JPG/PNG/WebP 复查资料，单文件不超过 20MB。
- 提交后 B端生成随访打卡、患者消息和任务事件。
- 异常反馈应进入待人工处理状态。

## 5. 数据范围

- 患者只属于一个科室。
- 患者只有一个主要负责医生。
- 健康管理中心、乳腺科、甲状腺科、呼吸科四个科室存在且可用。
- 不使用协作科室。
- 不使用督办意见。

## 6. 回归命令

后端语法检查：

```bash
python3 -m py_compile backend/routes/hospital_routes.py backend/routes/public_followup_routes.py backend/routes/miniprogram_routes.py backend/scripts/hospital_e2e_smoke.py
```

医院场景端到端冒烟测试：

```bash
cd backend
python3 scripts/hospital_e2e_smoke.py
```

前端构建：

```bash
cd vue-prototype
npm run build
```
